# ActiveCRM — מערכת ניהול לקוחות (גרסת הדגמה)

מערכת CRM כללית בעברית (RTL) להדגמה מול לקוחות. רצה ישירות בדפדפן — ללא התקנה, ללא שרת, ללא אינטרנט.

## הפעלה
לחיצה כפולה על `index.html`. זהו.

## מה יש במערכת
| מסך | תוכן |
|---|---|
| **לוח בקרה** | 4 מדדי KPI (לחיצים), גרף הכנסות 12 חודשים, פילוח מקורות לידים, עסקאות מובילות, משימות קרובות |
| **לקוחות** | 16 לקוחות לדוגמה · הוספה, עריכה ומחיקה · חיפוש, סינון לפי סטטוס/נציג, מיון · **ייבוא וייצוא CSV** |
| **צינור מכירות** | לוח קנבן ב-6 שלבים (כולל "נסגר בהפסד") · **גרירה ושחרור** · לחיצה על כרטיס = עריכה מלאה · מחיקה · סינון לפי נציג |
| **משימות** | הוספה, **עריכה**, מחיקה, סימון ✓ · פתוחות / להיום / באיחור / הושלמו · סינון לפי נציג |
| **יומן פעילות** | תיעוד ידני של שיחות ופגישות · עריכה ומחיקה · סינון לפי סוג, לקוח ותקופה |
| **דוחות** | ביצועי נציגים, משפך המרה, לקוחות מובילים · **הדפסה/PDF וייצוא CSV** |
| **הגדרות** | פרטי עסק ומטבע, **ניהול צוות המכירות**, עריכת נתוני גרף ההכנסות, גיבוי ושחזור, איפוס |

בנוסף: חיפוש גלובלי (`/` לפתיחה, Enter לתוצאה הראשונה); `Esc` לסגירת חלונות; מצב כהה/בהיר; תצוגה מותאמת לנייד.

### כרטיס לקוח מורחב
לחיצה על שורה בטבלת הלקוחות פותחת מסך רחב (920px) עם:
- **5 מדדים** — מספר תיעודים, זמן מאז הקשר האחרון (צבע לפי ותק), היקף עסקי, שווי בצנרת, משימות פתוחות
- **4 לשוניות** — תיעודים (ברירת המחדל), סקירה, עסקאות, משימות
- **תזכורת למחר** — יוצרת משימת מעקב מוכנה
- **עדכון מיידי** של סטטוס, אחראי ומקור ליד — בלי להיכנס לעריכה, וכל שינוי נרשם ביומן
- **פעולות** — עריכה, עסקה, משימה, חיוג, וואטסאפ, מייל, העתקת פרטים, שכפול, הדפסת כרטיס, מחיקה
- **תגיות** — הוספה והסרה בלחיצה, וכוכב ★ לסימון VIP

### לשונית התיעודים
הלשונית הראשונה בכרטיס, ומרכז העבודה מול הלקוח:

**טופס תיעוד** — בחירת סוג (שיחה · פגישה · מייל · וואטסאפ · הצעת מחיר · הערה), תיאור חופשי,
תאריך ושעה, משך בדקות, ותוצאה (הושלם / לא ענה / ממתין לתשובה / נקבעה פגישה / נשלח חומר / נדחה / לא רלוונטי).
תיבת סימון אחת יוצרת גם **משימת מעקב** בתאריך שתבחרו. כל תיעוד מעדכן אוטומטית את תאריך הקשר האחרון.

**כפתורי תיעוד מהיר** בראש הכרטיס קופצים לטופס עם הסוג כבר נבחר והסמן בשדה הטקסט.

**יומן מקובץ** — מוצמדים 📌 · היום · 7 הימים האחרונים · 30 הימים האחרונים · קודם לכן.
כל רשומה מציגה סוג, שעה, משך, תוצאה ומי רשם אותה, וניתנת להצמדה, עריכה ומחיקה.

**חיפוש וסינון** בתוך התיעודים של הלקוח, **ייצוא ל-CSV** ו**הדפסת יומן** מסודר.

### לוגיקה עסקית שמתעדכנת לבד
- העברת עסקה ל**"נסגר בהצלחה"** מוסיפה את סכומה להיקף העסקי של הלקוח ומסמנת אותו כלקוח פעיל — והחזרתה אחורה מבטלת את התוספת.
- כל שינוי שלב, סגירת משימה או הוספת הערה נרשמים אוטומטית ביומן הפעילות ומעדכנים את תאריך "קשר אחרון".
- שינוי שם נציג מעדכן את כל הלקוחות, העסקאות והמשימות שלו; מחיקת נציג מעבירה אותם לנציג אחר.

## נתוני הדגמה
כל השמות, החברות ומספרי הטלפון הם **דוגמאות בדיוניות**. התאריכים מחושבים יחסית להיום, כך שההדגמה תמיד נראית עדכנית.

השינויים נשמרים ב-`localStorage` של הדפדפן. לפני הדגמה מול לקוח חדש — **הגדרות ← איפוס לנתוני דוגמה**.

## התאמה אישית
- שמות, חברות ונתונים: `assets/data.js`
- צבעים ועיצוב: משתני ה-CSS בראש `assets/styles.css` (למשל `--brand`)
- לוגיקה: `assets/app.js`

## מבנה
```
index.html
assets/
  styles.css
  data.js
  app.js
```

## ייבוא לקוחות מקובץ CSV
כותרות הקובץ (שורה ראשונה), בקידוד UTF-8:
```
שם,חברה,טלפון,אימייל,עיר,תחום,סטטוס,מקור,אחראי,היקף עסקי,קשר אחרון
```
הדרך הפשוטה: ייצוא CSV מהמערכת → עריכה באקסל → ייבוא חזרה.
